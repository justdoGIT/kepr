## Installation

<Tabs items={['Linux', 'macOS', 'Docker / Container']}>
  <Tab value="Linux">
    ```bash
    git clone https://github.com/aikepeer/kepr.git && cd kepr
    ./install.sh
    ```
    Installer builds release binaries and configures standalone user mode or systemd service.
  </Tab>
  <Tab value="macOS">
    ```bash
    git clone https://github.com/aikepeer/kepr.git && cd kepr
    cargo build --release --bins
    cp target/release/kepr target/release/kepr-daemon /usr/local/bin/
    cp systemd/io.kepr.daemon.plist ~/Library/LaunchAgents/
    launchctl load ~/Library/LaunchAgents/io.kepr.daemon.plist
    ```
  </Tab>
  <Tab value="Docker / Container">
    ```bash
    docker run -d --name kepr-eso ghcr.io/aikepeer/kepr-eso-provider:latest
    ```
  </Tab>
</Tabs>

## Basic Usage

<Steps>
  <Step title="Store a credential">
    ```bash
    # Masked interactive input
    kepr set OPENAI_API_KEY
    
    # Or auto-generate hex / password
    kepr set DB_PASSWORD --generate --gen-kind pass
    ```
  </Step>

  <Step title="Deliver secrets via RAM (Zero /proc leaks)">
    ```bash
    # Delivers secrets via sealed in-memory file descriptors (memfd)
    kepr exec --memfd OPENAI_API_KEY -- python train.py
    ```
  </Step>

  <Step title="AI Coding Agents (planned)">
    Sealed agent sessions (`kepr agent run`) are in development; see the
    [agent vault plan](/docs/agent-vault-plan). `kepr protect-agent` is
    disabled until they ship.
  </Step>

  <Step title="Argon2id Store Lock & Unlock">
    ```bash
    # Lock the master key with Argon2id passphrase
    kepr lock
    
    # Check protection status
    kepr status
    
    # Unlock when needed
    kepr unlock
    ```
  </Step>
</Steps>

## Integrations

### Git Credential Helper
```bash
git config --global credential.helper kepr
```

### Docker Login Helper
In `~/.docker/config.json`:
```json
{
  "credsStore": "kepr"
}
```

### Direnv Integration (`.envrc`)
In your project `.envrc`:
```bash
source_env completions/kepr.envrc
use_kepr OPENAI_API_KEY ANTHROPIC_API_KEY
```
