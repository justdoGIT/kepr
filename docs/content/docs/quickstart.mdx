## Prerequisites

- Linux with **systemd** (the daemon is a systemd unit; the encryption
  backend ships with systemd).
- Stable Rust toolchain (`rustc`, `cargo`) — only at build time.
- `bash`, `sudo` access for installation.

## Install

<Steps>
  <Step title="Clone and build">
    ```bash
    git clone <repo> kepr && cd kepr
    chmod +x install.sh
    ./install.sh
    ```

    The installer runs `cargo build --release`, creates the `kepr`
    system group, installs both binaries, and starts
    `kepr.service`.
  </Step>

  <Step title="Activate group membership">
    ```bash
    newgrp kepr          # or log out / in
    groups | grep kepr   # verify
    ```

    <Warning>
      Without active group membership, `kepr` cannot connect to
      `/run/kepr/kepr.sock` (it is `0660 root:kepr`).
    </Warning>
  </Step>

  <Step title="Verify the daemon is reachable">
    ```bash
    systemctl status kepr
    kepr list            # empty list, no error
    ```
  </Step>
</Steps>

## Store and retrieve

<Tabs items={['Generate', 'Interactive (masked)', 'Non-interactive']}>
  <Tab value="Generate">
    ```bash
    kepr set OPENAI_API_KEY --generate
    kepr set BOB_TOKEN --generate --gen-kind pass
    ```
  </Tab>
  <Tab value="Interactive (masked)">
    ```bash
    kepr set OPENAI_API_KEY
    # Value for OPENAI_API_KEY (blank = auto-generate): ***
    ```
  </Tab>
  <Tab value="Non-interactive">
    ```bash
    kepr set OPENAI_API_KEY --value sk-abc123
    ```
  </Tab>
</Tabs>

```bash
kepr get OPENAI_API_KEY               # pretty
kepr get OPENAI_API_KEY --quiet       # raw value, for $(...) capture
kepr get OPENAI_API_KEY --export      # 'export OPENAI_API_KEY=...'
eval "$(kepr get OPENAI_API_KEY --export)"
```

## Routine operations

```bash
kepr list                             # alias: ls
kepr check                            # decrypts every cred; exit 1 if any fail
kepr delete OPENAI_API_KEY            # interactive confirm
kepr rm OPENAI_API_KEY --force        # no prompt
```

## JSON mode for scripts

`--json` emits one JSON object on stdout. On clean errors (missing arg,
unknown verb), nothing goes to stderr.

```bash
kepr --json list | jq '.credentials[].name'
kepr --json get DOES_NOT_EXIST          # {"kind":"err","error":"..."} ; exit 1
```

## Audit log

```bash
journalctl -t kepr-daemon                          # tail
journalctl -t kepr-daemon KEPR_UID=1000         # one user
journalctl -t kepr-daemon KEPR_OP=get           # one op
journalctl -t kepr-daemon KEPR_RESULT=fail      # only failures
```

<Check>
  The credential value is never logged — only `op`, `name`, `uid`,
  `user`, and `result`.
</Check>
