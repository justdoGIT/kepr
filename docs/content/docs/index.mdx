`kepr` is a per-user secret vault for Linux and macOS, written in Rust. It eliminates plaintext `.env` file leaks, `/proc/<pid>/environ` snooping, and shell history exposures by delivering secrets directly into memory via **RAM-sealed memory descriptors (`memfd`)**.

## Key Security Properties

- **RAM-Based Execution (`kepr exec --memfd`)**: Secrets pass via sealed, read-only memory file descriptors (`KEPR_FD_<KEY>=3`).
- **Zero Plaintext on Disk**: Master key protected by Argon2id + AES-256-GCM; credentials stored in AES-256-GCM authenticated envelopes.
- **Kernel-Attested Peer Isolation**: The daemon reads peer identity (`SO_PEERCRED` / `LOCAL_PEERCRED`), preventing header-forgery attacks.
- **Structured Audit Logging**: Operations log to system journal with op/uid/result; secret values are never logged.
