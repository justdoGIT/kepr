## Command surface

| Verb     | Aliases | Args                                                | Output                |
| -------- | ------- | --------------------------------------------------- | --------------------- |
| `set`    |         | `KEY [--generate] [--value V] [--gen-kind ...]`     | `SetOk`               |
| `get`    |         | `KEY [--quiet] [--export]`                          | `GetOk { value }`     |
| `list`   | `ls`    | —                                                   | `ListOk { credentials }` |
| `delete` | `rm`    | `KEY [--force]`                                     | `DeleteOk`            |
| `check`  |         | —                                                   | `CheckOk { all_ok }`  |

Global flags: `--json` (machine output, suppress stderr on clean
errors), `--color` / `--no-color` (opt-in ANSI), `--version`, `--help`.

## Generators (`--gen-kind`)

| Kind     | Length | Format                                                  |
| -------- | ------ | ------------------------------------------------------- |
| `hex`    | 64     | `[0-9a-f]` from 32 random bytes (default).              |
| `base62` | 48     | `[A-Za-z0-9]`, rejection-sampled (no modulo bias).      |
| `pass`   | 32     | upper + lower + digit + symbol (retry until all four).  |
| `uuid`   | 36     | RFC 4122 v4 (version + variant nibbles enforced).       |

All entropy comes from `/dev/urandom`. The rejection-sampling helper
discards bytes ≥ `(256 / |alphabet|) * |alphabet|` to stay uniform.

## Audit log

Every operation emits a structured journal datagram via a cached
`UnixDatagram` fd:

```
SYSLOG_IDENTIFIER=kepr-daemon
PRIORITY=6 | 3
MESSAGE=kepr: op=get name=OPENAI_API_KEY uid=1000 user=kk result=ok
KEPR_OP=get
KEPR_NAME=OPENAI_API_KEY
KEPR_UID=1000
KEPR_USER=kk
KEPR_RESULT=ok
```

Indexed query examples:

```bash
journalctl -t kepr-daemon
journalctl -t kepr-daemon KEPR_UID=1000
journalctl -t kepr-daemon KEPR_OP=get KEPR_RESULT=fail
```

<Check>
  The credential value is never logged — only `op`, `name`, `uid`,
  `user`, `result`.
</Check>

## Per-user isolation

Credentials live in the shared `/etc/credstore.encrypted/` directory,
namespaced by uid:

```
kepr-1000-openai-api-key      # uid 1000
kepr-1001-openai-api-key      # uid 1001 — same name, different file
```

The daemon takes the uid from `SO_PEERCRED` on the socket, **not**
from the request payload, so users can only see and operate on their
own credentials.

## Environment variables

| Variable           | Effect                                                |
| ------------------ | ----------------------------------------------------- |
| `NO_COLOR`         | Any value disables ANSI (overrides `--color`).        |
| `CLICOLOR_FORCE=1` | Enables ANSI without `--color`.                       |

Precedence: `NO_COLOR` > `--no-color` > `CLICOLOR_FORCE` > `--color` > off.

## Exit codes

- `0` on success.
- `1` on any error, including `check` with at least one failed credential.
